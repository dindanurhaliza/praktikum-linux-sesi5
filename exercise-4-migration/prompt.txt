Buat script bash untuk migrasi data dari log teks biasa ke format SQL INSERT statements. Data input adalah file log dengan format: TIMESTAMP|LEVEL|SERVICE|MESSAGE. Script harus membaca file tersebut baris demi baris, lalu mengubah setiap baris menjadi format query SQL: INSERT INTO app_logs (created_at, log_level, service_name, log_message) VALUES ('timestamp', 'level', 'service', 'message'); dan menyimpannya ke file output/migration.sql. Berikan contoh data log sebanyak 5 baris di dalam penjelasannya agar bisa saya gunakan sebagai testing.
